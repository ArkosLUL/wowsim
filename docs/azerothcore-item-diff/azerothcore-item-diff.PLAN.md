# AzerothCore vs WotLK Classic item-data investigation

## Context

This wowsim fork was built for WotLK Classic. The user wants to rework it for their AzerothCore (3.3.5a)
server, whose item data differs (e.g. Ulduar ilvls are higher in Classic). **End goal of the later rework:**
the sim sources item stats, ilvls, sockets, and set membership from the server (item_template + DBCs);
Wowhead stays only for icons, phases, and loot sources.

This task is **investigation only**: build a reusable, read-only server-data package plus a diff tool, run
it, and write a findings report the rework can execute from. No changes to sim logic, `gen_db`, or the server.

## Execution order

1. `git switch -c azerothcore-item-diff` (user-approved). Leave all work **uncommitted** for user review.
2. Save this plan as `docs/azerothcore-item-diff/azerothcore-item-diff.PLAN.md`.
3. Build `tools/database/azerothcore/` with unit tests, then `tools/database/acdiff/`, section by section
   (items → obtainability → effects/sets → gems/enchants), checking each against the known facts below.
4. Run the tool, review output, write the investigation report.

## Established facts

## Package: `tools/database/azerothcore/` (reusable by the future `gen_db -gen=azerothcore`)

- **MySQL reader** (`github.com/go-sql-driver/mysql`, SELECT only). Default DSN
  `root:password@tcp(127.0.0.1:3306)/acore_world`. Reads `item_template` (entry, name, Quality, ItemLevel,
  InventoryType, class, subclass, stat_type1-10/stat_value1-10, armor, ArmorDamageModifier, *_res, block,
  dmg_min1/dmg_max1, delay, socketColor_1-3, socketBonus, GemProperties, spellid_1-5, spelltrigger_1-5, Flags,
  AllowableClass, itemset, RandomProperty, RandomSuffix, ScalingStatDistribution), `spell_proc`, and the
  obtainability sources (below).
- **DBC reader**: minimal WDBC (header `WDBC`, recordCount, fieldCount, recordSize, stringBlockSize; 4-byte
  fields; string block). Files come from `-dbcDir` if set, else `docker cp <acContainer>:/azerothcore/env/dist/data/dbc/<file>`
  into an OS temp dir (default container `ac-worldserver`). Typed accessors: Spell (Effect[3], EffectDieSides,
  EffectBasePoints[3], EffectApplyAuraName[3], EffectMiscValue[3], EffectTriggerSpell[3], EffectItemType[3],
  ProcChance, DurationIndex, Name/Description enUS), SpellItemEnchantment (Effect[3], EffectPointsMin[3],
  EffectArg[3], Name), ItemSet (Name, ItemID[17], SetSpellID[8], SetThreshold[8]), GemProperties (EnchantId,
  Type), SpellDuration. Validate indices on known rows (65019 → "Mjolnir Runestone", bp+1 = 665).
- **Conversion** row → `proto.UIItem` / `proto.UIGem` stats:
  - `stat_type` → sim index: 0 Mana, 1 Health, 3 Agi, 4 Str, 5 Int, 6 Spi, 7 Sta, 12 Defense, 13 Dodge,
    14 Parry, 15 Block, 16/17 MeleeHit, 18 SpellHit, 19/20 MeleeCrit, 21 SpellCrit, 28/29 MeleeHaste,
    30 SpellHaste, 31 hit (7+12), 32 crit (8+13), 35 Resilience, 36 haste (9+14), 37 Expertise, 38 AP (11+21),
    39 RAP, 41/42/45 SP, 43 MP5, 44 ArP, 47 SpellPen, 48 BlockValue. Confirm against sim samples
    (46019 AP in 11+21; 45110 hit in 7+12).
  - Equip spells (`spelltrigger` = 1) with flat-stat auras: 13 MOD_DAMAGE_DONE / 135 MOD_HEALING_DONE → SP,
    99 → AP, 124 → RAP, 85 MOD_POWER_REGEN (misc 0) → MP5, 189 MOD_RATING (misc = CombatRating mask) → rating,
    22 MOD_RESISTANCE, 158 → BlockValue, 123 → SpellPen, 29 MOD_STAT. Other auras are effects, never guessed into stats.
  - Armor → 20, ArmorDamageModifier → 34; weapon min/max/speed (`delay`/1000); sockets 1 Meta, 2 Red,
    4 Yellow, 8 Blue → GemColor; socket bonus / gem stats via SpellItemEnchantment effect 5 (stat, arg =
    ItemModType) and 4 (resistance); heroic = `Flags & 0x8`; class allowlist from AllowableClass.
  - Random-property / ScalingStatDistribution items marked "not comparable".
- **Unit tests**: DBC reader (hand-built WDBC fixture bytes), stat_type mapping, equip-spell stat resolution,
  socket/gem color mapping.

## Diff tool: `tools/database/acdiff/` (thin main)

Run: `go run ./tools/database/acdiff` (flags with defaults: `-dsn`, `-acContainer ac-worldserver`, `-dbcDir ""`,
`-acRepo G:/DevStuff/GitHub/azerothcore-wotlk-pb`, `-simDb assets/database/db.json`,
`-leftoverDb assets/database/leftover_db.json`, `-spellTooltips assets/db_inputs/wowhead_spell_tooltips.csv`,
`-simSrc sim`, `-outDir docs/azerothcore-item-diff/data`). Outputs CSVs + `summary.md`, all **tracked**.

- **Module attribution**: text-scan `<acRepo>/modules/**/*.sql` and `data/sql/custom/**/*.sql` for each diffed
  item entry / spell ID; tag rows with the files. Module-modified diffs go in their own section everywhere.
- **Items** (all simmable items in `db.json`): diff ilvl, quality, stats vector, armor/bonus armor, weapon
  damage/speed, sockets, socket bonus, heroic, class allowlist. → `items_diff.csv` (id, name, sim vs AC per
  differing field, sim source zone + difficulty, module files), `items_missing_on_server.csv`.
- **Obtainability**: an item is obtainable on the server if referenced by `creature_loot_template`,
  `gameobject_loot_template`, `reference_loot_template`, `item_loot_template`, `npc_vendor`,
  `game_event_npc_vendor`, `quest_template` RewardItem1-4 / RewardChoiceItemID1-6, or a Spell.dbc
  create-item effect (24 / 157, `EffectItemType`).
  - `items_unobtainable_on_server.csv`: sim items not obtainable, with their sim sources (surfaces Classic-only
    sources: Animated Constellation vendor 207128, Titan Rune dungeons, Hallow's End).
  - `items_missing_in_sim.csv`: obtainable, equippable, Quality ≥ 3, ItemLevel ≥ 187 server items absent from
    `db.json`, tagged if in `leftover_db.json` or the `overrides.go` deny lists.
- **Effects** (every sim item, gem, and enchant with a spell attached: trinkets, weapon procs, on-use, relics,
  meta gems, enchant types 1/3/7): walk spell + `EffectTriggerSpell` chain; 3.3.5 values = bp+1 per effect,
  duration s, ProcChance or `spell_proc.Chance`, `spell_proc.Cooldown`/1000. Classic values = numbers in the
  same spell IDs' tooltip text (HTML stripped). A 3.3.5 value absent from Classic numbers → mismatch. Locate Go
  by grepping `-simSrc` for item ID and aura spell IDs; record file:line and whether the 3.3.5 literal appears
  in the block. → `effects_diff.csv` (verdict: match / differs / manual).
- **Set bonuses**: sim `setName` → ItemSet.dbc by enUS name (fallback: set containing the item IDs); same
  comparison per SetSpellID/threshold; Go location via `Name: "<set name>"`; also diff set membership.
  → `sets_diff.csv`.
- **Gems/enchants**: sim `gems` ↔ `GemProperties` → GemProperties.dbc → SpellItemEnchantment (stats, color;
  gems missing on server). Sim `enchants.effectId` → SpellItemEnchantment: types 5/4 stats, type 2 weapon
  damage; spell types go through Effects. → `gems_diff.csv`, `enchants_diff.csv`.
- **`summary.md`**: counts per section; ilvl histogram grouped by zone + difficulty (zone names from `db.json`);
  Classic-vs-3.3.5 vs module-modified split.
